# Contributing

Bug reports and focused pull requests are welcome.

1. Search existing issues before opening a new one.
2. Do not include Discord tokens, logs containing private paths, or other personal data.
3. Run `go test ./...` and `go vet ./...` before submitting a pull request.
4. Keep Vencord repair behavior delegated to the official Vencord Installer CLI.

By contributing, you agree that your contribution is licensed under GPL-3.0.
